Sprout Tracker: developer guide

A one-page app to track how tall your plants grow. Built by Claude Code inside Buildscape. Plain HTML, CSS and JavaScript, no build step and no server.

Run it

Open index.html in a browser. Run the checks with npm test (runs node tests.js).

Files

  • index.html: the page: the add-plant form and the container for plant cards. Loads storage.js then app.js.
  • styles.css: colors, card layout and a phone layout (@media).
  • app.js: all the rules: addPlant, removePlant, addMeasurement, removeMeasurement, calculateGrowth, chartPoints and the render functions. startApp wires the buttons on load.
  • storage.js: savePlants and loadPlants, a thin wrapper around localStorage.
  • tests.js: plain Node checks of the pure rules in app.js.

How the parts talk

Screen (button click) → rule in app.js changes the plant list → savePlants stores it → render redraws the cards. On load, loadPlants → render.

Data

Stored in localStorage under plant-growth-tracker as an array of { id, name, measurements: [{ id, date, height }] }.

Good next steps

  • Export and import the data as a file, so it can move between devices.
  • Units setting (cm or inches).
  • Reminders to measure each week.
